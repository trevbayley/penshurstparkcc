# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub Security Advisories:

1. Open the repository's **Security** tab.
2. Choose **Private vulnerability reporting**.
3. Provide a clear description, affected URL/file, reproduction steps, impact, and suggested fix.

Do not publish a vulnerability in a public issue or discussion before it has been reviewed and fixed.

Please allow reasonable time for triage and remediation. For active exploitation or a severe incident, include the observed impact and time discovered so it can be prioritised.

## Scope

In scope:

- The published GitHub Pages site and its custom domain
- Repository source used to build or publish the site
- Security misconfiguration that can affect visitors

Out of scope:

- Automated scanning noise without a demonstrated security impact
- Social engineering
- Denial-of-service testing
- Third-party platforms not controlled by this project

## Safe testing

Test only accounts and data you own or have permission to test. Do not access, modify, or expose other people's data.
